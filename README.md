# 🎓 EduPlatform — University Landing Page

> Talabalar uchun qulay, ishonchli va zamonaviy ta'lim platformasi.

🔗 **Demo:** [najmiddin2016.netlify.app](https://najmiddin2016.netlify.app/)

---

## 📖 Loyiha haqida

**EduPlatform** — universitet yoki ta'lim markazi uchun mo'ljallangan landing sahifa. Sayt yangi talabalarni jalb qilish, platforma imkoniyatlarini tanishtirish va kurslarni taqdim etish maqsadida yaratilgan.

---

## ✨ Asosiy bo'limlar

| Bo'lim | Tavsif |
|---|---|
| 🏠 **Hero** | Platforma haqida qisqacha tanishtiruv va CTA (chaqiruv tugmasi) |
| 📊 **Ishonch statistikasi** | "25K+ Students" — platformaga bo'lgan ishonchni ko'rsatuvchi raqamlar |
| 💼 **Paketlar/Xizmatlar** | Books Library, Sales Planning, Evaluation Time — asosiy xizmatlar kartalari |
| 🎥 **Kurslar** | Video-kurslarni ko'rish imkoniyati |
| 🔐 **Sign in** | Foydalanuvchi tizimga kirish tugmasi |

---

## ✅ Nima uchun bu loyiha yaxshi?

- **🎯 Aniq maqsadga yo'naltirilgan struktura** — tashrif buyuruvchi bir necha soniyada platforma nima haqida ekanini tushunadi.
- **📈 Ishonch elementlari** — "25K+ Students" kabi statistikalar orqali yangi foydalanuvchida ishonch uyg'otadi.
- **🗂️ Tizimli taklif** — xizmatlar alohida kartalarda, tushunarli va tartibli tarzda joylashtirilgan.
- **🧭 Qulay navigatsiya** — Home, Contacts, About us, Blog bo'limlari orqali kerakli ma'lumotga tez yetish mumkin.

## 🎯 Nima uchun qulay?

- **Bitta sahifada barcha muhim ma'lumot** — qo'shimcha sahifalarga o'tmasdan platforma haqida tasavvur hosil bo'ladi.
- **Vizual ierarxiya** — sarlavha, statistik ko'rsatkich va xizmatlar ketma-ket, mantiqiy tartibda joylashgan.
- **Tezkor kirish** — "Sign in" tugmasi orqali ro'yxatdan o'tgan foydalanuvchi darhol tizimga kira oladi.
